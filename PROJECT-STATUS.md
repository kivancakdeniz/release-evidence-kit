# Project Status

Release Evidence Kit is a public pre-draft design review. This repository contains research, architecture decisions, a threat model, and a non-normative format sketch.

## What exists

- A defined problem and narrow non-goals.
- A proposed evidence chain and predicate shape.
- A delivery and falsification plan.
- A static bilingual project page.

## What does not exist

- No approved specification.
- No JSON Schema or conformance vectors.
- No example bundle that has passed independent verification.
- No reference CLI, review server, verifier, npm package, or GitHub Action.
- No implementation may claim conformance to this pre-draft.

## Status progression

`pre-draft` -> `draft` -> `approved`

A status change requires an ADR, updated machine-readable metadata above, and the release gates in [docs/ROADMAP.md](docs/ROADMAP.md). Draft and approved status also require the dedicated Community Specification repository and its legal/governance package.

## Archival state

If work stops, this file will change to `status: archived`, the final known limitations will be recorded, and the repository will remain readable as design history. No adopter should depend on unreleased commands or schemas described here.
