# Türkçe Teknik Dokümantasyon

> Bu belge, İngilizce [kaynak metinlerin](../) bilgilendirme amaçlı Türkçe çevirileri için indekstir. Yorum farkında İngilizce metin geçerlidir.

## Statü uyarısı

Bu repository, **public pre-draft design review** niteliğindedir. Onaylanmış bir
specification veya yayımlanmış bir reference implementation değildir.
`SPEC-DRAFT.md` bir ön taslak planlama çalışmasıdır ve normatif değildir.

Türkçe belgeler yalnızca bilgilendirme amacı taşır. Teknik yorum, kapsam veya
anlam farklılığı hâlinde ilgili İngilizce kaynak geçerlidir.
