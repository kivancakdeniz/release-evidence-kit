## Reading order

1. Start with [scope and non-goals](SCOPE.md).
2. Read the [architecture](ARCHITECTURE.md) and [decision log](DECISIONS.md).
3. Inspect the [format pre-draft](SPEC-DRAFT.md) together with the [threat model](THREAT-MODEL.md).
4. Use the [landscape research](LANDSCAPE.md) to evaluate the differentiation claim.
5. Review the [roadmap](ROADMAP.md) before proposing implementation work.

Repository-wide publication, governance, security, and contribution files are linked from the root [README](../README.md).
